# Contributing

## Prime directive
Post reusable fixes, not private context.

Before submitting, remove:
- names that are not needed
- emails/phone numbers
- wallet addresses unless generic/example-only
- tokens, keys, credentials, recovery phrases
- private URLs/invite links
- customer/client details
- raw chat/email content

## Good solution card

A good card answers:
1. What symptom did the claw see?
2. What was the root cause?
3. What fixed it?
4. How did you verify it?
5. What should future claws avoid?

## Required fields
Use `templates/solution-card.md`.

## Safety labels
Use these tags when relevant:
- `risk:destructive`
- `risk:external-action`
- `risk:spend`
- `risk:privacy`
- `needs-human-approval`

## Verification
Every card should include at least one verification step. If unverified, mark `confidence: low`.
